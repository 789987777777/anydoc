Any document in.

anydoc is a Rust library that converts Word, PowerPoint, Excel, OpenDocument, RTF, EPUB, CSV, and PDF files to GitHub-Flavored Markdown. This page runs it as WebAssembly, entirely in your browser: files never leave your machine.

About

          

            Every format parses into one shared document model and renders
            through one Markdown serializer, so headings, lists, tables with
            merged cells, footnotes, and escaping come out the same whether the
            input was a .doc from 2003 or a
            .pptx from yesterday. The format is read from the
            bytes, not the extension, so mislabeled files still convert.
          

          

            It is pure Rust with no ML models and no services: median conversion
            is under 5 ms, and across
            a benchmark
            of 100 documents it was the only one of seven converters to handle
            all fourteen formats. Text-based PDFs go through
            pdf-inspector, locally, with no OCR service involved.
          

        


        

          
Install

          

            
Rust

            
$ cargo add anydoc

            
Node.js

            
$ npm install @firecrawl/anydoc

            
Python

            
$ pip install firecrawl-anydoc

            
Browser

            

              $ npm install @firecrawl/anydoc-wasm
            

            
CLI

            
$ npx @firecrawl/anydoc report.docx

            
Agent skill

            
$ npx skills add firecrawl/anydoc

          

          

            The API is the same everywhere: convert from a path or from bytes,
            or stop at the document model and keep the embedded assets. See the
            README.
